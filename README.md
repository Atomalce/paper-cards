# 纸间卡片

先想一想，再翻开答案。一款无需登录、没有运行时模型调用的中文抽认卡工具，把知识拆成可以自测的问题。

## 运行

安装 Python 3 后，在本目录运行 `python -m http.server 18082 --bind 127.0.0.1`，浏览器访问 `http://127.0.0.1:18082`。也可以使用任意静态网站服务器。无需安装前端依赖。

## 使用

1. 输入问题和答案，保存新卡片；也可载入三张使用说明示例。已有卡组载入示例前会要求确认替换。
2. 先自己组织答案，再点击卡片翻面。翻面后可标记“已经熟悉”或“继续练习”，并通过上一张、下一张切换。
3. 按全部、待练习或已熟悉筛选；搜索同时匹配问题和答案。列表支持选择、编辑和确认删除。
4. 使用“导出备份”下载 JSON；换设备或浏览器时，再导入该文件。导入是整组替换，已有卡片时会要求确认。

## 数据与限制

最多 500 张卡片，问题去首尾空白后 1–200 个 Unicode 字符，答案 1–2000 个字符。备份是 JSON 数组，每项仅包含 `id`（1–80 个字符且不重复）、`question`、`answer`、`known`（布尔值）。导入文件不得超过 2 MiB，全部校验通过后才替换数据，非法文件保留原卡组。数据通过 `textContent` 显示，不执行卡片里的 HTML。

卡片保存在当前网站来源的浏览器 localStorage 中，不会自动跨设备同步。清除浏览器数据、切换访问地址或隐私浏览可能导致卡片不可用，请定期导出。保存失败时会显示提示，应立即导出备份。多标签页可接收存储更新，但建议只在一个标签页编辑以避免覆盖。

熟悉度由使用者手动标记，不代表考试成绩。本应用不实现间隔重复算法，也不判断答案正确性。

## 实现与验证

`core.js` 的校验与筛选基础由华为云 AI 开发者空间 CodeArts 生成，随后修正字段白名单校验和数组类型校验；界面、交互及验证由 Codex 辅助完成。`index.html` 负责响应式布局，`app.js` 管理卡片状态、浏览器持久化和备份交互。

运行 `node --test core.test.cjs` 验证数据校验、Unicode 边界、重复 ID、500 张容量和筛选。界面已通过浏览器操作验证后，记录于作品发布资料中。
